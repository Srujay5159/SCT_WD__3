# 💻 Programming Quiz App

An interactive and responsive Coding Quiz Application developed using HTML, CSS, and JavaScript. This project provides a real-time quiz experience similar to an official coding assessment platform.

---

## 🚀 Features

✅ Multiple Programming Languages Quiz  
- HTML Quiz  
- CSS Quiz  
- JavaScript Quiz  

✅ Different Types of Questions  
- Single Choice Questions  
- Multiple Choice Questions  
- Fill in the Blank Questions  

✅ Official Exam Interface  
✅ Timer Based Quiz System  
✅ Randomized Questions on Every Attempt  
✅ Score Calculation System  
✅ Play Again & Finish Options  
✅ Responsive UI Design  

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
